# HapGAM 预注册（2026-10-20，开发开始前冻结）

本文件在任何模型训练之前写定。之后的修改只能追加在文末“修订记录”，并说明原因；锁箱结果出来后不得修改主终点。

## 1. 假设

- **H1（主）**：在“少数大效应位点 + 多基因背景”的性状上，HapGAM 在未见地区（组留出）场景中的预测精度不低于 max(GBLUP, LightGBM)，并在部分性状上更高。
- **H2**：HapGAM 在跨群体零样本迁移（GRIN→SoyNAM、GRIN→NUST）中优于 GBLUP。
- **H3**：随机划分下 HapGAM 与最强基线持平（差值 95% CI 覆盖 0 或为正）；产量等多基因性状上与 GBLUP 持平。
- **H4（可解释性）**：门控选中的非线性块富集在已知大效应基因附近（E1–E4、Dt1、Dt2、W1、T 等），阳性对照性状的选中块与已知基因位置一致。

## 2. 数据与划分（已冻结，`splits/grin_splits.tsv`，sha256 见同目录）

- GRIN × SoySNP50K（Wm82.a2）：17,407 份 *G. max*，38,016 个 SNP（无表型质控：检出率 ≥0.95、MAF ≥0.01，众数填充）。
- `lockbox_japan`（2,931 份，日本来源）：未见地区锁箱，开发期间不使用。
- `lockbox_random`（2,175 份，非日本来源 15%，按地区×熟期组分层）：随机锁箱，开发期间不使用。
- `dev`（12,301 份）：开发期只用这些材料做内层交叉验证（随机 5 折；按地区留出：中国、韩国、南/东南亚、美洲、欧洲、俄罗斯/中亚）。
- SoyNAM（5,176 个 RIL，40 个家系）与 NUST（北方统一区试，约 2,500 个品系）：开发期间不查看结果，只在冻结后运行一次。

## 3. 性状与目标

- 主终点性状（4 个）：成熟期（DOY）、开花期（DOY）、株高（cm）、百粒重（g）。
- 次要性状：产量、蛋白、油分、倒伏、熟期组（MG）。
- 目标值：按评价批次（GRIN `method_name`）中心化，批次均值只用训练折记录估计；同一材料多条记录取中心化值的平均。熟期组本身已标准化，不做中心化。
- 阳性对照（分类）：花色（W1）、茸毛色（T）、结荚习性（Dt1/Dt2）、荚色（L1/L2）、种皮色（I）。

## 4. 指标

- **主指标**：测试材料上预测值与批次中心化观测值的 Pearson r（材料层面）。
- 次指标：批次内 Pearson r 的平均（测试记录 ≥20 的批次）、Spearman、RMSE、前 20% 选择重合率。
- 分类对照：AUC。

## 5. 场景（主场景加粗）

| 代号 | 训练 → 测试 | 性质 |
|---|---|---|
| C1 | dev → lockbox_random | 随机留出，确认性 |
| **C2** | dev + lockbox_random → **lockbox_japan** | **未见地区，确认性（H1 主检验）** |
| C3 | 全部材料按地区轮换留出（7 个地区） | 组留出，日本以外为开发暴露数据 |
| C4 | 全部材料按熟期组轮换留出（5 组） | 外推，次要 |
| C5 | SoyNAM 随机 5 折、留家系（按家系分组 5 折） | 新群体，确认性 |
| **C6** | **GRIN → SoyNAM 零样本**（家系内 r） | **跨群体，确认性（H2）** |
| C7 | GRIN → NUST 零样本 | 跨群体，确认性 |

## 6. 模型

HapGAM：ŷ = μ + Xβ + Σ_b γ_b g_b(x_b) (+ 可选稀疏块间交互) + cᵀPC。线性部分以 REML-rrBLUP 初始化并保持同一岭惩罚；g_b 为零初始化输出层的小 MLP；γ 由组稀疏惩罚收缩。超参数（块尺度、惩罚强度、隐藏单元、学习率、训练轮数）只在训练集内层 CV 中选择。

基线：GBLUP/rrBLUP（REML）、BayesB、BayesC（BGLR）、RKHS（高斯核，带宽网格）、EGBLUP（加性+加性×加性核）、单倍型 GBLUP、LightGBM、XGBoost、MLP、DNNGP 类 CNN、堆叠集成（GBLUP+LightGBM+BayesB）。
调参预算：树模型与 HapGAM 使用相同的内层 CV 方案和相同的搜索次数上限；线性混合模型用 REML。

## 7. 统计

- 配对差值（HapGAM − 基线）：C1/C2 用材料层面 bootstrap（2,000 次）给出 95% CI；C3/C4 以留出组为单位汇总并报告逐组差值；重复 k 折用 Nadeau–Bengio 校正 t 检验；多个性状用 Holm 校正。
- 深度模型 5 个随机种子，报告均值 ± 标准差及种子平均集成。

## 8. Go/No-Go（开发期，dev 内层 CV）

若 HapGAM 相对 max(GBLUP, LightGBM) 在 4 个主性状的组留出 r 上平均提升 < 0.01 且 bootstrap 95% CI 含 0，则不再增加复杂度，转为：①作为集成成员证明互补性；②以可解释性与迁移为主要卖点；③如实报告。

## 9. 锁箱规则

- 锁箱（lockbox_random、lockbox_japan、SoyNAM、NUST）只在代码与配置冻结后各运行一次，冻结时记录代码哈希。
- 任何锁箱结果出来后不再调整模型；如需再测试，只能使用新的、未接触的数据。

## 修订记录

### 修订 1（2026-10-20，任何 HapGAM 训练之前；只基于 dev 折上的 GBLUP 与描述性统计）
- **改动**：目标值由“按批次中心化”改为“折内混合模型去批次效应”：在训练记录上拟合 y = μ + b_batch + g + e（g 的协方差为基因组关系矩阵 K，批次为固定效应），从训练和测试记录中减去估计的批次效应，再按材料平均。测试记录若落在训练中未出现的批次，则不进入合并指标（只进入批次内 r）。
- **原因**：GRIN 评价批次按熟期组组织（例如 2KY81 只含 MG IV–V，成熟期批次内 SD 仅 2.9 天），批次中心化会把熟期组之间的遗传差异一并去掉，使成熟期在 dev 随机 5 折上的 GBLUP r 只有 0.44–0.48、遗传力约 0.42；基因组关系矩阵把不同批次的材料联系起来，使批次效应只吸收环境差异。
- **影响**：所有模型共用同一套缓存目标（`data/processed/targets/`）；锁箱未被触及。原中心化目标下的 GBLUP 结果归档在 `runs/_superseded/`，不作任何结论。

### 修订 2（2026-10-20，开发期；只基于 dev 内层/外层折，锁箱未触及）
- **改动**：HapGAM 的“线性/随机效应主干”除 GBLUP（K_A）外，增加 EGBLUP 主干：协方差 (1−w)K_A + w·K_AA（K_AA 为 K_A 的 Hadamard 平方，按平均对角线缩放），w ∈ {0, 0.25, 0.5, 0.75, 1} 在训练集上按 REML 似然选择；w=0 即原 HapGAM，M=0 即 EGBLUP。块筛选始终使用加性 REML-GBLUP 的标记效应。两种主干都报告（HapGAM-A、HapGAM-E），并保留 HapGAM-linear（块内线性）作为消融。
- **原因**：dev 地区留出中 EGBLUP 对株高明显优于 GBLUP（0.610 vs 0.567），按“架构把最强基线作为特例”的原则，HapGAM 应能嵌套 EGBLUP。
- **影响**：主终点、指标、划分不变；冻结前确定最终主模型（HapGAM-A 或 HapGAM-E），选择规则只用 dev 结果，冻结时记录代码哈希。

### 决策规则（2026-10-20 22:47 写定，dev 结果尚未完整）
- **主模型选择**：在 dev 地区留出（dev_region）上比较 HapGAM-A 与 HapGAM-E 在 4 个主性状上的平均 Pearson r（逐折平均后再对性状平均），取较高者为主模型；两者之差 < 0.002 时取 HapGAM-E（因其嵌套最强核基线 EGBLUP）。另一变体作为次要结果报告。
- **确认期网格**：若计算资源不足以在全部确认场景使用完整网格（3 种块大小 × M∈{8,16,32,64} × 2 种权重衰减 + M=0），只允许收缩为 dev_region 各外层折内层 CV 实际选中过的配置集合（并始终保留 M=0）；收缩只依据 dev 结果，且在任何确认场景运行前写定。树模型的调参预算不随之减少（保持 25 次）。
- **Go/No-Go**：按第 8 节，比较对象为 max(GBLUP, LightGBM)；同时报告相对 EGBLUP 的差值。
